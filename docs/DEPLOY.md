# Размещение в интернете (Vercel + Supabase)

## 0. Перед выкладкой (на вашем компьютере)
1. `npm run lint`, `npm run typecheck`, `npm test`, `npm run build`. Все четыре команды должны пройти без ошибок. Ошибки сборки лучше исправить до публикации.
2. Убедитесь, что в Supabase выполнены миграции 0001–0008 по порядку.

## 1. Размещение через Vercel CLI (без GitHub)
1. `npx vercel login`, вход через браузер или почту.
2. В папке проекта: `npx vercel link`. Ответы: создать новый проект, имя `graphite-renovation`, корневая папка `./`.
3. В панели vercel.com откройте проект → **Settings → Environment Variables** и добавьте для Production (и Preview):
   - `NEXT_PUBLIC_SUPABASE_URL` — Project URL из Supabase;
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY` — anon (или publishable) ключ;
   - `NEXT_PUBLIC_APP_NAME` — название приложения.
   Ключи `service_role`/`secret` НЕ добавляйте: приложению они не нужны.
4. `npx vercel --prod` — вернёт адрес вида `https://graphite-renovation.vercel.app`.
5. Region функций: Settings → Functions → выберите регион, ближайший к вашему проекту Supabase (меньше задержка).

## 2. Альтернатива: GitHub
Создайте репозиторий (приватный), отправьте код (файл `.env.local` в репозиторий не попадает: он в `.gitignore`), в Vercel нажмите **Add New → Project**, выберите репозиторий, добавьте те же переменные. Дальше каждое обновление в GitHub публикуется автоматически.

## 3. Настройка Supabase для боевого адреса
**Authentication → URL Configuration:** Site URL = адрес сайта; в Redirect URLs добавьте адрес сайта и `http://localhost:3000`.
Подтверждение почты на боевом сайте лучше ВКЛЮЧИТЬ (Confirm email) и настроить собственную почтовую службу (SMTP): встроенная отправка Supabase имеет жёсткие лимиты.

## 4. Проверка после выкладки
- Откройте сайт с телефона по ссылке, зарегистрируйтесь, создайте заявку с фото.
- Откройте `/install` и установите на главный экран.
- Проверьте все роли в разных браузерах.

## 5. Важно перед реальным запуском
- Тарифы: бесплатный план Vercel Hobby предназначен для личных и некоммерческих проектов. Для работы компании нужен платный план. Условия могут меняться: проверьте на vercel.com/pricing.
- Бесплатный Supabase «засыпает» при долгой неактивности и ограничен по размеру и письмам. Для компании нужен платный план и резервные копии.
- Замените демо-данные: цены, тексты, контакты (админка → Настройки, Каталог).
- Юридические тексты должен проверить юрист.
- Пароли для staff-аккаунтов используйте надёжные и разные.
- Домен: Vercel → Settings → Domains, DNS у регистратора.

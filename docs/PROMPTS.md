# Промпты для Claude Code (запускать по одному, в каждом: «сначала прочитай CLAUDE.md и docs/TZ.md»)

## Этап A. Основа и безопасность
Создай Next.js (App Router, TS strict, Tailwind), подключи токены Graphite из `src/styles/tokens.css`, общие компоненты (Button, Input, Card, Table, Chip, Toast, Modal, Empty/Error/Loading-состояния) по `docs/design-reference.html`. Подключи @supabase/ssr, middleware для сессии, серверные хелперы `requireUser`/`requireRole`. Подними локальный Supabase (`supabase start`), примени миграцию 0001, исправь ошибки. Напиши RLS-тесты (клиент не видит чужое, мастер только назначенное, роль не повысить, статус не сменить напрямую, Storage). Gate: lint, typecheck, test, build.

## Этап B. Публичный сайт
Главная (13 блоков из ТЗ 5.1), каталог и страницы услуг, прайс из БД с поиском/фильтром/сортировкой, калькулятор на серверных ценах (`src/lib/pricing.ts`, сохранять снимок расчёта в заявку), портфолио, одобренные отзывы через `public_reviews`, контакты, юридические страницы-черновики. Seed с явно помеченными демо-данными. Gate как выше.

## Этап C. Авторизация и клиент
Регистрация (только клиент, согласие в `consents` с версией документа), вход, восстановление пароля. Создание заявки через серверное действие: валидация zod, идемпотентность по `idempotency_key`, загрузка фото в приватный бакет. Кабинет клиента: список, карточка, смета (согласовать/отклонить через RPC), доп. работы, фотоотчёты по signed URL, контакты мастера после назначения, отзыв. Gate.

## Этап D. Менеджер, мастер, администратор
Менеджер: дашборд с реальными счётчиками, список (поиск, фильтры, сортировка, пагинация), карточка, статусы через RPC, назначение мастера, визит, версии смет с неизменяемым снимком, заметки, модерация отзывов, редактирование прайса. Мастер: назначенные заказы, статусы, фото по этапам, доп. работы, свои контакты. Админ: пользователи и роли (серверное действие + audit_logs), блокировка, настройки, журнал. Gate.

## Этап E. PWA, QA, выпуск
Манифест и иконки, адаптивность без горизонтального скролла. Playwright: 15 сценариев из ТЗ 18.4 на тестовой БД. Проверки безопасности из 18.5 на уровне API/RLS/Storage. README, `.env.example`, инструкция Supabase и Vercel, итоговый отчёт по 10 разделам ТЗ (только реально выполненное).

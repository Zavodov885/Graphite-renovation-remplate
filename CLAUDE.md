# Graphite Renovation — правила проекта для Claude Code

Полное ТЗ: `docs/TZ.md` (положить файл ТЗ сюда). Это источник истины. Визуальный эталон: `docs/design-reference.html` (открыть в браузере, это кликабельное превью всех ролей и цветов).

## Уже принятые решения
- Акцент: лайм `#B8E600` (токены в `src/styles/tokens.css`, менять только там). Фон/карточки/границы как в токенах.
- Юрисдикция: Россия, 152-ФЗ. Юридические страницы — черновики с пометкой «требует проверки юристом».
- Деньги: `numeric(12,2)` в БД, целые копейки в коде, округление half-up на уровне позиции (`src/lib/pricing.ts`).
- Роль берётся только из `profiles.role`. Регистрация создаёт клиента. Метаданные Auth для ролей не читать.
- Статус заказа меняется только через RPC `change_order_status`; мастер назначается через `assign_master`; решения клиента через `decide_estimate`, `decide_extra_work` (миграция `supabase/migrations/0001_init.sql`).
- Service role key только на сервере. Фото только в приватном бакете `order-photos`, путь `{order_id}/{file}`, доступ через signed URL.
- Без чата, уведомлений, оплаты, интеграций с мессенджерами (ТЗ, часть XX).

## Что уже есть
Миграция 0001 (схема, RLS, RPC, Storage-политики), логика расчёта и статусов с тестами, токены, `.env.example`.
Миграция и тесты НЕ проверялись на живой базе: первым делом прогнать `supabase start && supabase db reset` и `npm test`, исправить найденное.

## Порядок работы
Идти по `docs/PROMPTS.md`, этап за этапом. Не переходить дальше, пока не проходят: `npm run lint`, `npm run typecheck`, `npm test`, `npm run build`. В отчёте указывать только реально запущенные проверки.

# Graphite Renovation
Каркас проекта по ТЗ. Состояние: готовы миграция БД, бизнес-логика и тесты, дизайн-токены, эталон интерфейса. Приложение Next.js ещё нужно построить по `docs/PROMPTS.md` (Claude Code на вашем компьютере).

Старт: `npm install`, `cp .env.example .env.local`, `supabase start`, `supabase db reset`, `npm test`.
Эталон интерфейса: открыть `docs/design-reference.html`.
